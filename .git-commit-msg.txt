Wire up the review workflow state machine end-to-end (build order step 6)

transitions -- the full chain from pending_bplo_initial through to
released.

- lib/review-workflow.ts: shared submitDepartmentDecision (used by
  both a department's own action and BPLO acting on their behalf --

  displaying uploaded documents on staff dashboards -- private bucket,

  finalizeAssessment (status transition only -- fee engine is step 7),
  submitDepartmentDecisionAsBplo (rule #9, tagged acted_on_behalf).

- Department actions: submitOwnDepartmentDecision, using the shared
  helper so RLS (migration 0002) is the actual rule #8 enforcement,
  not application code re-checking department scope.
